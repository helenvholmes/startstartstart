# Changelog

What changed in each version of the *startstartstart!* plugin. The version is the one in `.claude-plugin/plugin.json`.

## 1.1.0 (20 November 2026)

- New sites get a favicon while they're being built: the person's logo if they shared one, otherwise their initials in the site's own font and colors, with an icon for phone home screens too.
- The interview now asks whether they'd like a testimonials section. Quotes go on the site word for word, with the person's name and role, and the section is hidden at launch if no real ones are in yet.

## 1.0.1 (20 November 2026)

- Added a [privacy policy](https://startstartstart.app/privacy/), linked from the plugin's listing and this folder's README.

## 1.0.0 (20 November 2026)

- First version submitted to Claude's plugin directory: the `start` and `accounts-setup` skills.
